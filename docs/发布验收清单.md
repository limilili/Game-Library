# 库集 v2.2 发布验收清单

> 目的：确认陌生用户拿到分享包后，能够安全完成「解压 → 启动 → 扫描 → 分类 → 写回」。
> 建议在虚拟机或另一台没有装过本项目的电脑上执行。

---

## 一、分享包检查

- [ ] 分享包是 `dist\库集v2.1` 压缩后的 zip，不是单个 `kuji.exe`
- [ ] 解压后目录里有 `kuji.exe`、`alembic.ini`、`client\resources\metadata_prebuilt.db`
- [ ] 解压路径中不包含你自己电脑的 `config.yaml`、`kuji.db`
- [ ] 用杀毒软件扫描一次分享包（Nuitka 打包有时会被误报，需要提前确认）

## 二、首次启动

- [ ] 双击 `kuji.exe` 能正常打开，不闪退
- [ ] 首次启动后 `%APPDATA%\KuJi\config.yaml` 自动生成
- [ ] 主窗口标题显示「库集 v2.2」
- [ ] 不填任何 Key，程序也能正常打开

## 三、扫描

- [ ] 点击「扫描游戏库」能完成，不长时间无响应
- [ ] 扫描完成后游戏数量和 Steam 库大致一致
- [ ] 没有封面的游戏显示占位图，而不是消失
- [ ] 左侧分类树有数量显示
- [ ] 如果没填 Steam API Key，扫描能降级，不崩溃

## 四、多选与分类

- [ ] 点击「多选」后，树形分类点击有勾选反馈
- [ ] 厂商页面点击厂商条目有勾选反馈
- [ ] 风格标签点击有勾选反馈
- [ ] 级联视图仍然明确提示「多选模式下不支持级联」
- [ ] 手动分类后，左侧分类数量更新

## 五、AI 功能（可选）

- [ ] 没配置 AI 时，点击「AI 补全/分类」有明确提示
- [ ] 配置 AI 后，点击前有费用/耗时确认框
- [ ] AI 每轮最多处理 50 款，超出部分下次继续
- [ ] 进度条取消按钮能真正停止后续请求
- [ ] API 报错时弹窗显示具体错误（Key / 模型名 / 余额等）

## 六、写回 Steam（最高风险，必须做）

- [ ] 写回前确认 Steam 已完全关闭
- [ ] 点击「应用到 Steam」或「全量写回」有明确确认框
- [ ] 写回前自动生成备份，位置 `%APPDATA%\KuJi\.backup`
- [ ] 写回成功后有验证通过提示
- [ ] 打开 Steam，检查收藏夹是否正确，没有多余/丢失
- [ ] 设置 → 备份与恢复 → 「打开备份文件夹」可用
- [ ] 设置 → 备份与恢复 → 「恢复最近一次备份」可用（建议先用测试收藏夹验证）

## 七、反馈与清理

- [ ] 点击「反馈」能生成 zip
- [ ] 反馈包里 `config_sanitized.yaml` 不包含明文 API Key
- [ ] 反馈包里 `README.txt` 有 QQ 群号 1107903014
- [ ] 反馈包不包含 `kuji.db`
