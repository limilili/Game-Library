库集 v2.2 使用说明
=================

一、这是什么
库集是一个 Steam 游戏库分类工具：
- 扫描你本机的 Steam 游戏库
- 根据内置元数据和分类规则给出分类建议
- 你可以手动调整分类
- 可把分类结果写回 Steam 收藏夹

二、首次使用
1. 完全解压分享包（不要只复制 kuji.exe）
2. 双击 kuji.exe
3. 点击左上角"扫描游戏库"
4. 扫描完成后，左侧可以看到分类树和分类数量
5. 可以手动分类，也可以点击"多选"批量处理

三、写回 Steam 前必须注意
1. 写回前必须完全退出 Steam（右下角托盘退出）
2. 写回前程序会自动备份
3. 备份位置：%APPDATA%\KuJi\.backup
4. 如果收藏夹出现异常：设置 → 备份与恢复 → 恢复最近一次备份
5. 建议先用少量游戏或测试分类验证，再全量写回

四、AI 功能（可选）
- AI 补全/分类需要自己填写 AI API Key、Base URL、Model
- AI 调用会把游戏名称和 AppID 发送给 AI 服务商，可能产生费用
- 不配置 AI 不影响扫描和手动分类
- 每轮最多处理 50 款，可随时取消

- 反馈包内不含明文 API Key，不含 kuji.db
- 反馈时请尽量提供：问题描述、复现步骤、截图、反馈包

六、隐私说明
- 本软件不自动上传你的游戏库
- 你填写的 API Key 只保存在本机：%APPDATA%\KuJi\config.yaml
- 使用 AI 功能时，相关游戏名称/AppID 会发送给你配置的 AI 服务商

七、免责声明
本软件会修改 Steam 收藏夹相关数据，使用前请确认你已了解风险。
请务必在写回前关闭 Steam，并按提示保留备份。
因误操作、Steam 客户端更新、云同步冲突等造成的收藏夹异常，
请优先使用"设置 → 备份与恢复"恢复备份。
